# Fraunhofer UMSICHT — Carbon2Chem technical center

Official page:
https://www.umsicht.fraunhofer.de/en/carbonmanagement/carbon-cycle/technical-center.html

Collected: 2026-07-25.

The Carbon2Chem technical center covers about 3,700 m2 adjacent to
thyssenkrupp Steel Europe in Duisburg. It contains laboratories and pilot
facilities for gas purification, methanol and ammonia synthesis, adsorption
and analytical work using real metallurgical gases from coke ovens, blast
furnaces and basic oxygen furnaces.
