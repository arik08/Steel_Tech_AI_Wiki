# ResponsibleSteel Decarbonisation Progress Levels

ResponsibleSteel's International Production Standard requires a site to measure
embodied crude-steel greenhouse-gas emissions and follow detailed accounting
rules intended to support global comparison. Four progress levels run from a
2022 global-average reference toward Level 4, near-zero steel.

The framework uses a scrap-variable approach. Scrap is a direct route to lower
emissions, but global supplies are constrained and unevenly distributed; simply
reallocating existing scrap can cause carbon leakage without a net global gain.

For Progress Level 1, a site using 20% scrap must be at or below
2.34 tCO2e/t crude steel, while a site using 80% scrap must be at or below
0.96 tCO2e/t crude steel. These thresholds include Scope 1, Scope 2 and upstream
Scope 3 emissions. Independent recognised certification bodies audit qualifying
sites.
