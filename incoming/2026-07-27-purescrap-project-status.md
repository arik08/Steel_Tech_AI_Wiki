# PURESCRAP project website capture

- 원문: https://purescrap.eu/
- 발행자: PURESCRAP consortium
- 수집일: 2026-07-27
- 자료 유형: 프로젝트 공식 사이트

## 확인 내용

- 사이트는 프로젝트 기간을 2023년부터 2026년 6월까지로 표시한다.
- 프로젝트는 2단계로 진입했으며 shredded scrap 센서 스테이션은 Stena Recycling Hallstahammar, heavy scrap 스테이션은 Swerim Luleå에 설치됐다고 설명한다.
- 센서 스테이션에서 분석한 스크랩은 VASD와 SSAB로 보내 화학분석을 검증할 예정이라고 설명한다.
- 사이트는 추가 세부 결과를 후속 공개할 예정이라고 적고 있어, 설치 사실과 제강 성능 달성을 구분해야 한다.
