## Verified technical configuration

- A non-steady physical blast-furnace model predicts hot-metal temperature
  8–12 hours ahead.
- Machine learning predicts the temperature 2–3 hours ahead, and an AI model
  learns operator practices.
- Online data are used to correct physical-model parameters.
- Candidate manipulated variables include blast moisture, pulverized-coal
  injection rate and blast temperature.
- The system can provide guidance to an operator or pass recommended actions
  directly to the control system for an available fully automatic heat-control
  mode.

## Company-reported result and boundary

- JFE says application at its blast furnaces reduced hot-metal temperature
  variation by 13% when operators followed the guidance, from sigma 15.9 C to
  14.0 C.
- This is company-reported solution-page evidence. The page does not identify
  the sites, furnace count, test period, number of heats, confidence interval,
  independent validation or fleet-wide deployment.
- The reported 13% result is tied to operator-followed guidance. Availability
  of fully automatic mode does not prove that the result was achieved in
  closed-loop autonomous operation or that all JFE furnaces use that mode.
